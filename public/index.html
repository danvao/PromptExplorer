GIT EN TU COMPUTADORA

Repositorio local o GitHub

▱
Carpeta de este perfil

Usa una carpeta existente o conecta un repositorio por SSH. Cada perfil conserva su propia selección.

En Mac puedes copiar la ruta de una carpeta desde Finder con ⌥⌘C. En Windows, usa “Copiar como ruta”. No selecciones la carpeta .git.

Obtén la URL en GitHub → Code → SSH. Admite dominios Enterprise y alias de tu configuración SSH.

Preparar SSH y SSO
  1. Genera una llave SSH en tu computadora y carga únicamente la llave pública (.pub) en GitHub → SSH and GPG keys.
  2. Si tu organización usa SSO, busca Configure SSO → Authorize junto a la llave.
  3. Carga la llave en ssh-agent o el almacén seguro de tu sistema.
  4. Prueba en tu terminal: ssh -T git@github.com. Verifica el host y que GitHub muestre la cuenta correcta. Sustituye github.com por tu dominio o alias si es necesario.

La app utiliza SSH de tu sistema. No solicita ni guarda llaves privadas. No puede pedir la frase de paso ni aceptar un host desconocido: prepara la conexión en tu terminal primero.

Crear versión guarda un commit local. Después, Sync GitHub descarga y publica. Si las ramas divergieron, resuelve la combinación en tu herramienta Git; la app conserva tus commits. No se crean PRs ni se fuerzan publicaciones.

Tu flujo de trabajo
  1. Edita y guarda los Markdown aquí.
  2. Pulsa Crear versión y escribe el comentario del commit.
  3. En modo local, haz pull/push con tu herramienta habitual. En modo GitHub, usa Sync GitHub. Los conflictos se resuelven con tu herramienta Git.
  4. Vuelve aquí: la app relee la carpeta al recuperar el foco o cada 10 segundos, si no tienes un borrador sin guardar. También puedes pulsar Actualizar.

El selector de perfiles recuerda una carpeta por perfil y navegador. Si eliges la misma carpeta en dos perfiles, ambos comparten archivos. Los commits usan tu identidad Git existente; el nombre del perfil no la sustituye.
